# Jarvis UI (Vite + React + Tailwind)

This folder contains the new frontend app for Jarvis.

Quick start (from `desktop/ui`):

```bash
npm install
npm run dev
```

Build for production:

```bash
npm run build
```

Preview built app:

```bash
npm run preview
```

Notes:
- This scaffold sets up Vite, React and Tailwind. Install `shadcn/ui` and any additional UI or icon libraries as desired.
- The app should call the backend endpoints at `http://localhost:3000` (or wherever your Express server runs). Configure a proxy in `vite.config.js` if needed during development.
